The 26-Row Indicator Register

Version 1 tests seven domains through 26 measurable indicators. Each row names what's actually being measured, where the evidence comes from, at what geographic level, how often it updates, whether the data currently exists, and how confident we can be in it. This is the ontology before the rankings — the Maryland/Virginia Evidence Matrix comes next, once these 26 rows are populated with real sources.

26 indicators 7 domains 0 weighted — averaging domains is deferred to v2 MVP v0.1, not yet populated with live data
YES

Data currently exists in a usable public form.

PARTIAL

Some data exists but is incomplete, scattered, or requires reconstruction.

WEAK

Data exists in principle but current sourcing is thin or unreliable.

NO

No public dataset yet — this is a CDI construction, not a lookup.
